Start your demo

  1. Install the MetaMask browser extension and use a separate demo wallet profile.
  2. Add network DecentraPay Local: RPC http://127.0.0.1:8545, chain ID 31337, currency ETH.
  3. Import the public test account listed in README.md. The app expects .
  4. Connect the wallet, select an amount, and start fingerprint verification. Approve the payment when MetaMask opens.

Simulator mode uses a fake fingerprint and a visual servo cycle, but a real local-chain transaction. Hardware mode requires the ESP32 over USB.

After restarting the blockchain, clear this demo account’s activity in MetaMask if it reports a stale nonce. Full wiring and enrollment instructions are in docs/HARDWARE.md.
